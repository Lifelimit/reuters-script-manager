# 📘 Reuters Script Manager

Practical, user-focused guide for running scripts with the Reuters Script Manager desktop app.

---

## 🎯 What You Can Do

- 🔐 Compare Snyk vulnerability reports over time
- 🤖 Review DataDome verified bots and AI agents
- 📚 Open step-by-step User Guides in-app

---

## 🚀 Quick Start

1. Launch the app
2. Choose a script: Snyk or DataDome
3. Ensure required files are present (status indicators show progress)
4. Open the script’s User Guide from the top bar
5. Click Run when everything is ready

---

## 📊 Required Files

### Snyk Report Compare
- `Snyk Report CAT YYYY-MM-DD.xlsx` (latest report)
- `Snyk Vulnerability tracker.xlsx`

### DataDome Compare
- `DataDome_Export_AI_agents_YYYY-MM-DD.xlsx`
- `DataDome_Export_verified_bots_YYYY-MM-DD.xlsx`
- `DataDome Bots - Block or Whitelist.xlsx`

---

## 🧭 In-App Help

Open these guides directly from the app:
- Snyk: `Documents/Snyk Report Compare/Snyk_Compare_Script_User_Guide.md`
- DataDome: `Documents/DataDome Verified Bots Compare/DataDome_Compare_Script_User_Guide.md`

---

## ✅ Tips

- Keep files in the working directory shown in the details panel
- Use consistent naming and archive old files regularly
- Don’t interrupt the script while running
